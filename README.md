# Minecraft Server Discord Manager by TreSet
A Manager for your existing Minecraft Server on Linux, fully controlled through Discord.

## Features
- Event logging
  - Start / stop
  - Player join / leave
  - Player death [companion-mod only]
  - Player advancement [companion-mod only]
- Automatic backup
  - With or without server restart
  - Highly customizable schedule
  - Automatic upload to google drive
  - Integration with the game to notify players
- Server crash detection
  - Automatically restart the server when it crashes
- Discord commands for management
  - Start / stop / restart
  - Create Backup
  - Send a message to the server
  - Run a command on the server [companion-mod only]
- Many Discord commands for easy access of server information
  - Is the server online
  - What version the server is running
  - How to join the server
  - Who is allowed to join the server
  - Where to find backups
- Extensive configuration options
  - Enabling, disabling and gating of commands
  - Enabling and disabling of messages in game and in discord
  - Configuring message strings
- No proprietary server runner needed. Works with any server 1.21.9 and above (26.1 and above for client mod features).
